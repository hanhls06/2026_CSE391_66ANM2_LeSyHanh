# Nền tảng Phát triển Web (CSE391)

## Giới thiệu
Tài liệu này được xây dựng phục vụ giảng dạy và học tập cho môn  
**Nền tảng Phát triển Web (CSE391)** trong chương trình đào tạo đại học.

Nội dung môn học nhằm cung cấp các kiến thức nền tảng về phát triển ứng dụng web hiện đại,  
từ các công nghệ cơ bản phía trình duyệt đến kỹ thuật xây dựng ứng dụng web động và  
single-page application (SPA).

Tài liệu được thiết kế theo hướng kết hợp giữa **lý thuyết – thực hành – dự án**,  
giúp người học hình thành tư duy phát triển web một cách hệ thống và có khả năng  
áp dụng vào các bài toán thực tế.

---

## Mục tiêu môn học
Sau khi hoàn thành môn học, người học có khả năng:

- Hiểu và vận dụng các chuẩn **HTML5**, **CSS3** và **Responsive Web Design**
- Sử dụng **JavaScript (ES6+)** để xây dựng các chức năng tương tác phía client
- Thao tác và xử lý dữ liệu thông qua **DOM** và các cơ chế bất đồng bộ
- Phát triển **Single Page Application (SPA)** với các framework phổ biến như  
  **React**, **Vue.js** hoặc **Angular**
- Tích hợp và khai thác dữ liệu thông qua **RESTful API**
- Xây dựng một dự án web hoàn chỉnh làm cơ sở cho các học phần tiếp theo

---

## Nội dung chính
- Tổng quan về phát triển ứng dụng web
- Kiến trúc client – server và giao thức HTTP/HTTPS
- HTML5 Semantic và cấu trúc tài liệu web
- CSS hiện đại: layout, responsive design, preprocessor
- JavaScript cơ bản và nâng cao
- DOM manipulation và lập trình bất đồng bộ
- JavaScript frameworks và kiến trúc SPA
- Quy trình phát triển phần mềm và quản lý mã nguồn

---

## Cấu trúc học phần
Nội dung học phần được tổ chức theo **tuần học**, từ nền tảng đến nâng cao:

- Tuần 0: Tổng quan và định hướng công nghệ
- Tuần 1–3: HTML5 và CSS (cơ bản & nâng cao)
- Tuần 4: CSS Frameworks
- Tuần 5–6: JavaScript cơ bản, DOM và bất đồng bộ
- Tuần 7: JavaScript Frameworks
- Các tuần tiếp theo: Thực hiện và hoàn thiện dự án học phần
